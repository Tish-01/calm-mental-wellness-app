# Calm – Mental Wellness Support App

## Overview

Calm is a responsive web application designed to provide immediate support during moments of anxiety, stress, or panic.

The application offers a collection of calming tools including guided breathing exercises, grounding techniques, calming sounds, reassurance prompts, and interactive distraction games to help users regulate emotions and refocus attention.

---

## Features

### Guided Breathing
- Animated breathing exercises
- Visual breathing cues
- Panic-specific breathing support

### Grounding Exercises
- 5-4-3-2-1 grounding technique
- Sensory awareness prompts

### Reassurance System
- Rotating calming affirmations
- Emotional support messages

### Distraction Activities
- Color recognition game
- Counting exercise
- Animals A–Z challenge

### Comfort Mode
- Rain sounds
- Ocean sounds
- Forest ambience
- Fireplace sounds

### User Experience
- Fully responsive design
- Mobile-friendly interface
- Clean and calming UI
- No user data collection

---

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## Project Goals

This project was created to explore how front-end development can be used to create accessible digital wellness experiences that provide emotional support during moments of stress and anxiety.
